# Så visar du en profil-README på GitHub

GitHub visar automatiskt innehållet i `README.md` från ett offentligt repository som heter **exakt samma sak som ditt användarnamn**.

Ditt GitHub-användarnamn är `jakobozmen`. Bland de tillgängliga repositories jag kontrollerade fanns ännu inget separat repository med namnet `jakobozmen`.

## Så publicerar du texten när du är nöjd

1. Öppna https://github.com/new
2. Skriv `jakobozmen` som repositorynamn.
3. Markera `Public` och `Add a README file`.
4. Skapa repositoryt.
5. Kopiera innehållet från `GITHUB_PROFILE_README.md` i denna mapp till det nya repositoryts `README.md`.
6. Klicka `Commit changes`.
