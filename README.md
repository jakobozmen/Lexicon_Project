# Jakob Özmen – IT-portfolio

En responsiv personlig portfolio som visar min bakgrund inom IT-support, .NET-studier och projekt inom webb och databaser.

**[Besök min publicerade portfolio](https://jakobozmen.github.io/Lexicon_Project/)**

## Utvalda projekt

| Projekt | Tekniker | Beskrivning |
| --- | --- | --- |
| [Gävle Sjukhus](https://github.com/jakobozmen/gavle-sjukhus-access-database) | Access, VBA, SQL | Relationsdatabas, formulär, sökfunktioner och rapporter |
| [Lexicon Frontend](https://github.com/jakobozmen/Lexicon_Project) | HTML, CSS, JavaScript | Responsiv portfolio med interaktiva funktioner |
| Vargobservationer i Gävleborg | JavaScript, Leaflet, Supabase | Kursprojekt utan publik demo |

## Funktioner

- Anpassad för dator, surfplatta och mobil.
- Ljust och mörkt tema. Inställningen sparas lokalt.
- Projektfilter för webb och databas.
- Semantisk HTML, tangentbordsnavigering och stöd för minskad rörelse.
- Inga externa JavaScript-bibliotek.

## Starta lokalt

Klona eller ladda ner repositoryt och öppna `index.html` i din webbläsare. Ingen installation behövs.

## Projektfiler

- `index.html` – innehåll och projektnavigering
- `style.css` – layout, responsivitet och färgteman
- `script.js` – temaväxling och projektfiltrering
- `docs/GITHUB_PROFILE_README.md` – färdigt utkast till en GitHub-profil
- `docs/PROFILE_SETUP.md` – instruktioner för GitHub-profilens inställningar
